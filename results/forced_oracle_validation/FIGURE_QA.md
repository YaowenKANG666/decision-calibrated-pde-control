# Figure QA: persistent-forcing task validation

- Backend: Python/Matplotlib only.
- Core claim: the revised task benefits from active control before introducing
  a learned world model.
- Quantitative source: `case_metrics.csv`, 100 independently sampled physical
  cases, paired by case across controllers.
- Interval definition: 95% nonparametric bootstrap intervals with 5,000
  resamples; paired resampling is used for controller differences.
- Baselines: zero control and finite-budget PDE-oracle MPC.
- Export: editable SVG and PDF plus 600-dpi PNG. TIFF is generated by the
  script for submission workflows but ignored by Git.
- Visual inspection: axis labels, identity/reference lines, legends or direct
  labels, clipping, overlap, and readability at single-column width passed.
- Integrity note: case zero was fixed as the representative trajectory before
  inspecting outcomes; it was not chosen as the largest effect.
- Boundary: PDE-oracle denotes access to the numerical transition model. CEM
  does not certify a globally optimal action sequence.

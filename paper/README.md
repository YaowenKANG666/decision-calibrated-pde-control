# Preprint

The current manuscript is
[`decision_calibrated_robust_control.pdf`](decision_calibrated_robust_control.pdf).

The PDF reports a residual FNO world model, perturbation-scaled conformal
ambiguity sets, robust MPC, deterministic error propagation, and the controlled
Burgers and NS2D experiments. The code and source result files in the repository
are the reproducibility record.

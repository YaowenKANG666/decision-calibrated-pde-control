# Style profile

- State the failure mode before naming the method.
- Use “we study,” “we construct,” and “we test”; reserve “guarantee” for a
  theorem with all assumptions stated.
- Separate finite-sample one-step coverage, deterministic rollout bounds, and
  empirical closed-loop performance.
- Put the key ambiguity-set equation in the introduction.
- Report confidence intervals, tail costs, and paired seed-level differences.
- Describe FNO in one short experimental paragraph; move alternatives to an
  appendix.
- Include negative smoke results as design evidence, not as a headline result.

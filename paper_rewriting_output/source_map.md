# Source map

| Source | Role | Authority | Permitted claim |
|---|---|---|---|
| `src/unoc/` | Executable method | Primary project source | What is implemented |
| `results/` | Experimental evidence | Primary project source | Only metrics present in JSON files |
| `theory/error_propagation.md` | Proof sketch | Primary project source | Conditional deterministic bounds |
| Local DSC-DNO reports | Optional architecture background | User material | Backbone definition, not present contribution |
| Perturbation-based NS2D operator-UQ draft | Closest scale/calibration exemplar | Primary preprint | Clean/perturbed FNO scale, max score, simultaneous field event, data-scarce experiment organization |
| Chee et al. (L4DC 2024) | Conformal robust control | Published primary source | Conformal dynamics regions can robustify controllers |
| Srinivasan et al. (L4DC 2026) | OOD robust MPC | Published primary source | Weighted conformal covariance sets and robust OOD MPC |
| Johnstone and Cox (COPA 2021) | Conformal robust optimization | Published primary source | Link between conformal sets and robust optimization |
| Farahmand et al. (AISTATS 2017) | Value-aware model learning | Published primary source | Model error should reflect downstream value |
| Mouli et al. (ICML 2024) | OOD UQ for PDE surrogates | Published primary source | Common UQ can fail OOD; ensembles can help |
| Li et al. (ICLR 2021), Kovachki et al. (JMLR 2023), Lu et al. (NMI 2021) | Operator-learning foundations | Published primary sources | FNO, neural-operator, and DeepONet background |
| Ma et al. (TMLR 2024), Moya et al. (Physica D 2025) | Conformal operator UQ | Published primary sources | Functional/field calibration without a control interface |

Numerical claims must point to a committed metrics file. Literature teaches
positioning and methods; it is never used as a substitute for project results.
